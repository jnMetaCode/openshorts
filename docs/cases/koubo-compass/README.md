## 看图把关的实际判罚（引擎原话）

及格线是 6 分。这条片的候选几乎全军覆没：

```
镜头 hook 的 3 条候选都没过看图把关或都取不到（分数 2/2/1，及格线 6）
镜头 s1   的 3 条候选都没过看图把关或都取不到（分数 2/1/1，及格线 6）
镜头 s3   的 3 条候选都没过看图把关或都取不到（分数 2/1/1，及格线 6）
镜头 s4   的 3 条候选都没过看图把关或都取不到（分数 1/1/1，及格线 6）
镜头 outro 的候选一条都没判成（看图接口没响应），改用本机出图，不拿没判过的顶上
镜头 outro 的 3 条候选都没过看图把关或都取不到（分数 -/-/-，及格线 6）
```

**为什么这是对的而不是"失败"**：这条片讲的是地磁场、外核液态铁、磁北极漂移——素材库里根本
没有这些东西的实拍。免 key 的 Wikimedia / Openverse 检索是按关键词全文匹配，"compass" 会给你
一堆罗盘特写，跟"地球剖面里的液态铁在流动"毫无关系。**宁可现画也不放错图**：模型给 1–2 分，
引擎就把它们全退了，改用本机 FLUX 按画面意图画。

首屏那张地球剖面（左半是海陆、右半是熔融外核）就是这么来的——它不是检索到的，是照着
"地球内部有液态铁在流动"这句口播画出来的。

最后一镜还撞上了另一种情况：**看图接口没响应**，一条都没判成。这时引擎不会"拿没判过的顶上"，
同样退回本机出图，并把这件事写进 notes——**没被看过的画面不许悄悄上片**。

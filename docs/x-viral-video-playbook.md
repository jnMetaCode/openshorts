# X 爆款讲解视频手法（openshorts 制作规范）

> 来源：对 X 上 84 条高浏览视频帖的量化蒸馏 + 8 支头部视频（33万-1099万浏览）逐帧拆解。
> 原始数据与看片笔记在 mediahub `storage/distill-corpus/x-video/`（playbook.md / watch-notes.md）。
> 本文是把那份结论翻译成 openshorts 项目文件（project.json / storyboard）的可执行规范。

## 〇、开工前先回答：这片靠什么被转发？

爆款只有四种传播引擎，讲解视频能用其中三种。选不出引擎的选题不要做片。

| 引擎 | 转发动机 | 讲解视频怎么用 | 参考样本 |
|---|---|---|---|
| 情绪/立场 | 认同或愤怒 | 争议观点 + 画面证据交替 + 关键词高亮字幕 | elon 访谈切片 859万 |
| 聪明感 | "看我发现个聪明东西" | 熟悉事物的陌生组合、历史/生活梗嫁接技术概念 | Google 建国文档 384万 |
| 身份认同 | 转发=自我表达 | 真实工作流/build in public，零包装录屏 | levelsio 工作流 28万 |
| 奇观 | 难以置信 | 讲解片里=引用震撼演示片段（quoted clip）当证据 | 龙焰 POV 799万 |

## 一、分镜铁律（8/8 支样本成立或反向验证）

1. **第一镜即主体，禁止铺垫开场**。scene 1 的 background 必须直接是核心画面
   （quoted 演示片段 / 录屏 / 最强信息图），信息卡只能叠加其上。
   **品牌卡/logo/封面卡一律挪到片尾**——8 支样本里唯一 logo 开场的量级垫底。
2. **每 2-3 秒一次视觉推进**。同一画面静止不得超过 3 秒；靠 `delayFrames` 逐层入场、
   B-roll 切换、数字上屏来维持推进感（Grok 混剪节奏 ≈ 2.5 秒/镜头）。
3. **真实感 > 制作精度**（手机实拍 1099万 > 4K 大制作 561万）。
   能用 `assets/quoted/` 真实素材（yt-dlp 引用片段、录屏）就不要画 SVG；
   SVG 只用于信息图（对比/流程/数字），不模仿"实拍感"。
4. **字幕规则**：口播/观点句必须上字幕，**关键词用强调色高亮**（accent 色文字层）；
   纯演示/奇观段落零字幕，信息全在画面。
5. **结尾用画面/数字定格收**，不加口播总结陈词。署名/引用来源卡放最后 2-3 秒。
6. **时长不是门槛，"每秒值回注意力"才是**。优先 10-40s；讲解片可到 60-90s，
   但每个 3 秒窗口都要有新信息或新画面，删掉一切"过渡话"。

## 二、caption（发帖配文）与视频的分工

- 视频本身冲击力强 → caption 极简（≤1 句，levelsio "This is my workflow" 式）
- caption 承担钩子（反差论断/数字冲击）→ 视频前段必须立刻给对应证据画面
- 二者不得重复；禁止 "Try XX"/"新课程上线" 式广告腔（样本中全部垫底）
- 话题标签 1-2 个

## 三、落到 project.json 的检查清单（提交渲染前逐条过）

- [ ] 传播引擎已明确（写进 `production.style.mode` 旁注释或 `look` 字段）
- [ ] scene 1 background = 核心画面，无 logo/封面卡
- [ ] 品牌/署名卡在最后一个 scene
- [ ] 每 scene 内静止画面 ≤3 秒（用 delayFrames 分批入场核对）
- [ ] 引用素材走 `assets/quoted/` + 屏显署名 + assets.json 记 license/时间点（合规红线）
- [ ] 观点句有高亮字幕层；演示段无冗余字幕
- [ ] 结尾定格，无总结口播。**末镜必须设 `holdSeconds`**（旁白结束后多停 2-4 秒），
      否则署名/品牌卡的 `delayFrames` 会超出镜头长度，直接渲染不出来（实测踩过）
- [ ] 底部文字层避开字幕带（约 y=1400-1550 区间），署名/品牌卡放 y≥1580
- [ ] 口播文案里无"大家好/今天我们来聊/总结一下"等铺垫与收场套话
- [ ] caption 已按分工写好，标签 ≤2 个
- [ ] 渲染后抽帧自检：第 1 帧、每 20% 处、末帧（`ffmpeg -ss N -frames:v 1`）

## 四、工程注意（踩过的坑）

- storyboard/project.json 的每个 layer **必须显式带 `rotation` 和 `opacity`**，
  schema 无默认值，缺了渲染在该 scene 首帧直接崩（interpolate outputRange 报错）。
- `content/<id>/storyboard.json` 与 `projects/<id>.json` 内嵌 scenes 是两份，
  渲染只认 `projects/`，改分镜要两边同步。
- 渲染命令：`node scripts/render.mjs projects/<id>.json`；输出 `out/<id>.mp4`。
- 渲染管道出错时退出码可能被管道吞掉——验收看 `out/` 文件 mtime + 抽帧，不信 exit code。

# OpenShorts · 开片 — 发布与增长计划

> 对标 MoneyPrinterTurbo 的起势方式：名字说人话、零门槛第一条片、中文社区教程生态、赞助商推广位。我们多一样：真·AI 出片 + 成本可见 + 验收把关。

## 1. 仓库本身（不删不重建，见 ADR-013）
- README 第一屏：一句话定义 + 15 秒 hero GIF（口播科普从输入到成片的过程录屏）+ 三个入口（`npx openshorts` / 桌面端 / Docker）+ 成片表（每条标"由 OpenShorts 实际生成 · 来源/模型"）。
- 中英双 README（`README.md` 中文、`README-en.md` 英文），Description 双语，Topics 已补（short-video / ai-video-generator / minimax-h3 / local-first …）。
- 开 Discussions（已开）：置顶「晒成片」「求模板」两个主题；Issue 模板已有 bug/feature，M1 加「模板申请」。
- Roadmap 公开：`docs/v2/03-开发计划.md` 即路线图，每个里程碑发 Release 并附成片。

## 3. 赞助商与冠名（与 AO 共用一套关系）
- 出片供应商冠名"免费体验由 X 提供"：谁给积分/额度谁上；到期退中性档（沿用 AO 规则）。
- README 赞助位与 AO 主仓同排序；推广链接只挂真机跑通的供应商。
- 首批目标：秘塔（H3 同底模，短剧线天然）、火山（Seedance + 图片）、APIMart（多模型比价）。

## 4. 指标与看板（不靠遥测）
- GitHub：star / fork / Discussions 晒片数（公开可查）。
- npm 周下载（公开可查）。
- "10 分钟出第一条片"：邀请 5 位新手做录屏走查，M1 验收前完成。
- 平台端：官方账号发布的示例视频播放/涨粉，作为内容线有效性的旁证。

## 5. 增长杠杆（按性价比）
1. **模板即内容**：每个新模板配一条成片和一篇教程，模板名就是搜索词（"口播科普""AI 短剧""带货口播"）。
2. **成本对比页**：同一条片在本地 / 秘塔 / 火山 / Agnes 的耗时、花费、画质并排——AO 创意库已有同题比价的底子。
3. **awesome 列表与聚合站**：awesome-ai-video、awesome-chinese-llm、comfyui-wiki 投稿。
4. **课程联动**：AO 学院（aiolaola.com）开一节「用开片做口播号」。
5. **不做的**：买星、互赞群、刷 Trending——一次被标记，仓库就废了。

# OpenShorts · 开片 — 架构设计（v2）

## 1. 分层

```
┌──────────────────────────────────────────────────────────────┐
│  界面层  Web Studio（Vite/React，四步流程）· 桌面端 · CLI       │
├──────────────────────────────────────────────────────────────┤
│  OpenShorts Core（本仓库）                                     │
│   templates/   口播科普 · AI 短剧 · 图层动画（v1）              │
│   sources/     画面来源适配器：stock · local · cloud · layered  │
│   voice/       TTS（Edge TTS 免费默认 → AO type:tts）          │
│   captions/    字幕（TTS 时间轴 / whisper.cpp，沿用 v1）        │
│   compose/     合成（ffmpeg；短剧走 AO concat；图层走 Remotion）│
│   publish/     封面 · 标题 · 标签 · 平台尺寸预设                │
│   cost/        花费预览（调用 AO preflight）                    │
├──────────────────────────────────────────────────────────────┤
│  agency-orchestrator（npm 依赖，不 fork）                       │
│   DAG 引擎 · 角色库 · 视频/图片/TTS 供应商表 · 看图验收 · 花费预览│
│   短剧流水线模板 · resume/feedback · doctor 探测                │
├──────────────────────────────────────────────────────────────┤
│  本机能力  ffmpeg · sd.cpp/ComfyUI（可选）· whisper.cpp（可选） │
└──────────────────────────────────────────────────────────────┘
```

**与 AO 的边界（谁做什么）**

| 能力 | 归属 | 说明 |
|---|---|---|
| 写脚本 / 分镜 / 提示词（角色、DAG、验收） | AO | OpenShorts 只提供模板 YAML 与输入 |
| 云端出图 / 出片 / TTS 供应商 | AO | `VIDEO_PROVIDERS` / `API_PROVIDERS`，一处维护 |
| 看图验收、花费预览、resume/feedback | AO | 直接复用 |
| 素材库匹配（Pexels/Pixabay） | **OpenShorts → 反哺 AO 为 `type: stock`** | 先在 OS 实现，稳定后上提 |
| 本地生成（sd.cpp 适配器） | **OpenShorts → 反哺 AO 为视频供应商 `local-sdcpp`** | 同上 |
| 口播模板、发布规格、四步界面 | OpenShorts | 产品层 |
| 图层动画（Remotion）、七道质检 | OpenShorts（v1 资产） | 作为一种来源保留 |

原则：**能进 AO 的能力都进 AO**（其他 AO 用户也受益，赞助商展示也集中），OpenShorts 只留产品层。

## 2. 核心数据协议

沿用 v1 的 `projects/<id>.json`（版本化 JSON 是内核，界面/CLI/Agent 共读），扩展镜头的画面来源：

```jsonc
{
  "id": "kepu-001",
  "template": "koubo-kepu",            // 口播科普 | ai-drama | layered
  "line": "koubo",                      // koubo | drama
  "output": { "w": 1080, "h": 1920, "fps": 30, "platform": "douyin" },
  "script": { "topic": "…", "segments": [ { "id": "s1", "text": "…", "visualIntent": "…" } ] },
  "voice": { "provider": "edge-tts", "voice": "zh-CN-XiaoxiaoNeural", "speed": 1.0 },
  "defaults": { "visualSource": "stock" },
  "shots": [
    {
      "id": "s1", "segment": "s1", "durationSec": 4.2,       // 由配音实际时长驱动（沿用 v1 节奏重排）
      "visual": {
        "source": "stock",                                     // stock | image | local | cloud | layered
        "query": "city night traffic timelapse",               // stock 用
        "prompt": "…",                                         // image/local/cloud 用
        "provider": "pexels", "assetId": "12345", "seed": null,
        "cost": { "kind": "free" }                             // free | per-image | per-second(n)
      },
      "captions": [ { "start": 0, "end": 1.3, "text": "…" } ],
      "status": "approved"                                     // planned → ready → approved / rejected（沿用 v1）
    }
  ],
  "bgm": { "file": "…", "volume": 0.25 },
  "provenance": [ … ]                                          // 沿用 v1：每个资产的来源/模型/种子/时间
}
```

要点：
- 切来源只改 `shots[].visual`，脚本/配音/字幕不动。
- 短剧线的项目由 AO 运行结果反向生成（AO 的 `metadata.json` + `assets/` → 项目 JSON），这样界面统一。

## 3. 画面来源适配器接口

```ts
export interface VisualSource {
  id: 'stock' | 'image' | 'local' | 'cloud' | 'layered';
  /** 运行前估算：数量 / 秒数 / 是否免费（喂给花费预览） */
  estimate(shot: Shot, project: Project): CostEstimate;
  /** 产出一个镜头的画面文件（mp4 / png），带溯源信息 */
  produce(shot: Shot, project: Project, ctx: RunContext): Promise<VisualAsset>;
  /** 这台机器/这份配置能不能用（key 有没有、sd-cli 在不在、内存够不够） */
  availability(): Promise<{ ok: boolean; reason?: string; tier?: string }>;
}
```

### 3.1 stock（素材库）
- 关键词：由脚本步骤为每段输出 `visualIntent` + 英文 `query`（Pexels 英文检索更准）；同一项目内去重，避免连续两段同一条片。
- 检索顺序：本地素材夹（用户自有）→ 本地缓存 → Pexels → Pixabay；命中后按镜头时长裁切、按 9:16 智能居中裁剪（人物检测可选）。
- 失败降级：无结果 → 换关键词一次 → 退到 `image`（AI 配图）并在界面标注。
- 合规：记录 license 与作者到 provenance；发布规格里可选自动署名。
- 反哺 AO：稳定后做成 `type: stock` 步骤。

### 3.2 image（AI 配图）
- 直接用 AO `type: image`（供应商/模型由用户在 AO 密钥页配置），出 9:16 静帧 + Ken Burns 推拉（ffmpeg zoompan），免费素材没有合适片段时的兜底。

### 3.3 local（本地生成）
- 运行时：**stable-diffusion.cpp 的 `sd-cli`**（Metal / CUDA / CPU），不引入 Python 环境；ComfyUI 作为第二后端（有人已装时直接连 `127.0.0.1:8188`）。
- 硬件检测 → 档位表（按统一内存 / 显存）：

| 可用内存 | 推荐组合（H3） | 预期（实测/外推） |
|---|---|---|
| < 24 GB | 不提供 H3；推荐 LTX-Video 2B / Wan 1.3B（M2 待接） | 480p、分钟级 |
| 24–32 GB | `fl2va_pruned-UD-Q2_K_XL` + TE `Q2_K_M` | 640×384、1.6 s、**216 s**（M2 Max 32G 实测，ADR-004） |
| 32–48 GB | `fl2va_pruned-Q3_K/Q4_K` + TE `Q2_K_M` | 960×544、5 s、15–25 min（外推，待测） |
| ≥ 64 GB | Q4_K + TE Q4_K_M；或 h3.c 原生 Metal | 接近云端 768p 草稿 |
| NVIDIA 24 GB+ | Q4_K_M + 系统内存 ≥ 64 GB | 参考社区实测 |

- 模型按需下载到 `~/.openshorts/models/`，带校验与断点续传；界面明说"草稿档、约 N 分钟一条"。
- 参数：H3 固定 `cfg 1.0`、帧数对齐 `17k+5`、宽高 32 对齐；默认 4 步草稿 / 8 步精修两档。
- 反哺 AO：做成 `VIDEO_PROVIDERS` 的 `local-sdcpp`（shape: `local`），`ao doctor` 报 sd-cli 与档位。

### 3.4 cloud（云端 API）
- 完全复用 AO：`type: video` / `type: image` / `type: tts`，供应商表、探测、限速、成本预览、看图验收都在 AO。
- 短剧线就是 AO `短剧流水线.yaml`；口播线的"AI 出片"镜头是单步 `type: video`。

### 3.5 layered（图层动画，v1）
- 保留 Remotion 渲染与七道质检；作为一种来源出现在口播线的镜头级选择里（例如信息板 / 思维导图段落）。

## 4. 配音 / 字幕 / BGM / 合成
- 配音：默认 **Edge TTS**（免费、中文音色多，MPT 同款）；升级走 AO `type: tts`（OpenAI 兼容 `/audio/speech`）。
- 字幕：优先用 TTS 返回的时间戳；没有则 whisper.cpp（v1 已接本地 ASR 协议）。样式预设 3 套（抖音黄字描边 / 简约白 / 双语）。
- 节奏：**配音时长驱动镜头时长**（v1 的"旁白重排"），画面按镜头裁切，不拉伸。
- BGM：本地曲库（v1 `music` 脚本）+ 自动 ducking；短剧线走 AO concat 的 `bgm/voiceover/clip_volume`。
- 合成：口播线 ffmpeg（拼接 + 字幕 + 混音，libass 缺失时软字幕降级，沿用 AO 规则）；图层线 Remotion。

## 5. 界面（四步）
1. **输入**：话题/文案/故事；选内容线与模板。
2. **来源与花费**：项目级默认来源 + 镜头级覆盖；右侧花费预览（复用 AO preflight 文案）。
3. **预览与调整**：按镜头看画面/字幕/配音；单镜头换来源重出；验收未过一键重出（AO `--feedback`）。
4. **出片与发布**：1080P 竖版 mp4 + 封面 + 标题/标签；平台尺寸预设；导出 SRT。

技术：沿用 v1 的 Vite + React + Express 本地服务；AO 作为子进程/库调用（`ao run` + SSE 或直接 `import { run }`）。

## 7. 技术选型
- Node 20+ / TypeScript；AO 作为 npm 依赖（`agency-orchestrator@^0.19`）。
- 不引入 Python；本地推理只调外部二进制（sd-cli / ComfyUI HTTP）。
- 素材库 SDK：直接 fetch（Pexels/Pixabay REST 简单，不加依赖）。
- Edge TTS：`edge-tts` 协议的 Node 实现（社区包评估后定，或自实现 WebSocket）。

## 8. 安全与合规
- key 只存本机（沿用 AO `~/.ao` 与 v1 `.env`）；服务只监听 127.0.0.1。
- 素材 license 入 provenance；引用素材沿用 v1 `assets/quoted/` 约定。
- 真人肖像 / IP 角色提示词过滤沿用 AO 创意库规则。

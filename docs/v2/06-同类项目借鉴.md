# 同类开源项目拆解与借鉴清单（2026-08-30）

原则：只借**被用户验证过的机制**，不抄产品形态；每条写清"借什么 / 进哪个里程碑 / 不借什么"。

## 1. MoneyPrinterTurbo（119k★，Python/Streamlit，素材库 + TTS）
| 借什么 | 为什么 | 进哪 |
|---|---|---|
| **素材切换频率可调**（"支持视频片段时长设置，方便调节素材切换频率"） | 节奏是口播片的命；固定 2–4 秒不够，要让用户拨 | M1：项目级 `cutEverySec` + 镜头级覆盖 |
| **字幕六项可调**：字体、位置、颜色、大小、描边、背景 | 抖音黄字描边是刚需，平台风格各异 | M1：3 套预设 + 这六项自定义 |
| **字幕两种时轴**：TTS 时间戳（快、无 GPU）/ whisper（准） | 与我们的设计一致，确认默认用 TTS 时间戳 | M1 |
| **音色实时试听 + 音色列表** | 选音色前必须听 | M1：首跑引导与设置页 |
| **批量生成 N 条选最满意** | 抽卡是 AI 生成的常态 | M3（脚本×变量×音色），M1 先支持"同脚本换素材重出" |
| **本地素材夹作为来源** | 用户自有素材优先级最高 | M1：`stock` 检索顺序第一位 |
| **付费任务显式确认**（火山 Seedance 要点确认） | 我们已有花费预览，补一步"确认花费"再跑 | M1：preflight 后确认按钮 |
| **FAQ 痛点 → 体检项**：ffmpeg 找不到、`ulimit -n` 太小、whisper 模型下不下来 | 别人踩过的坑直接进 `openshorts doctor` | M1：doctor 加 ulimit / 模型缓存检查 |
| 不借：Streamlit 表单式界面、Python 环境依赖、单一线性流程 | 我们的差异化就是一行安装 + 可混用来源 | — |

## 2. ShortGPT（RayVentura，Python，"LLM 可读的剪辑语言"）

## 3. open-chat-video-editor（华南理工，2.8k★，检索 + 生成混合）
| 借什么 | 为什么 | 进哪 |
|---|---|---|
| **URL→视频**（网页链接转短视频） | 文章/公众号链接是中文创作者最常见的输入 | M2：输入模式加"链接"，抓正文 → 脚本 |
| **检索 + 生成混合**（先检索再用 SD 精修；CLIP 多模态匹配） | 素材库命中差时的兜底思路 | M1：素材候选 3 选 1 用 **AO 看图验收员按 visualIntent 打分排序**（我们已有的能力，比 CLIP 更懂中文意图）；M2：命中差 → AI 配图 |
| 教训："暂不支持中文字幕显示" | 中文字体必须内置并测试 | M1：内置一款开源中文字体（如思源黑体/霞鹜文楷）并在 doctor 里检查 |
| 不借：LAION/WebVid 数据集检索（许可与体积） | — | — |

## 4. 我们独有、以上都没有的
- 真·AI 出片三档（本地草稿 / 云端成片 / 混用），成本运行前可见。
- 看图验收：不只审 AI 出的片，也可以给素材库候选排序、给成片做最终把关。
- AO 角色库：脚本不是一个通用 prompt，而是"科普作者 / 抖音策略师 / 编剧"分工。
- 一行安装、桌面端、Docker 三入口；本地优先、key 不出本机。
